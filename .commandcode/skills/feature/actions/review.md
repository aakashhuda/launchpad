# Review Action

1. Read the `@context/current-feature.md` - to understand the goals
2. Review all the code changes made for this feature
3. Check for:
   - ✅ Goals met
   - ❌ Goals missing or incomplete
   - ⚠️ Code standard/quality issues or bugs
   - 🚫 Scope creep (code beyond goals)
   - ⚠️ Architecture not followed
4. Final verdict: Ready to complete or needs changes
