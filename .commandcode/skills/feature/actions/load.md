# Load Action

1. Check $ARGUMENTS (after load):
   - A filename is provided. Look at `@context/features/{filename}.md`/`@context/iterations/{filename}.md`/`@context/fixes/{filename}.md` location for the file
   - If the filename is empty: "Error! load requires a filename"
2. Update to current-feature.md
   - Update H1 with the feature name (eg. # Current Feature: Add Password Reset Functionality)
   - Write goals under ## Goals
   - Write any additional note/context under ## Notes
   - Set the status to 'Not Started'
3. Confirm the feature spec loaded and show the feature summary (very short)
